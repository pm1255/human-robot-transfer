# 机械臂视频修复汇总

已统一为灰色材质，并修复机械臂整段消失问题，明显的关节跳变已减小；加密人体分割后，已复查片段中的人手重新出现问题已改善。全片 4834 帧都有双臂可见。仍有中等程度的背景补全接缝、衣物纹理拉伸和接触不准确，影响合成真实感；当前适合视觉审阅，不可直接用于机械臂执行或动作训练。人体移除尚未完成全片逐帧人工真值验收。

## 本轮修改与证据

- 两臂使用相同的银灰色外壳、深灰关节和浅灰夹爪，不再用颜色区分左右。
- 全片 640 × 480、30 FPS、161.13 秒、4,834 帧，完整解码通过。最终渲染中，左臂缺失 0 帧、右臂缺失 0 帧；此处指每臂至少有可见像素，不代表完整机械臂始终在视野内。
- 按最短角差计算，旧版最大相邻帧关节跳变约 179.35°；新版约 3.43°。最大关节速度约 1.80 rad/s，最大加速度约 9.99 rad/s²。这是显示轨迹连续性指标，不是控制器验收。
- 固定估计焦距与尺度，稳定桌面坐标；连续求解关节位置，限制每次变化并平滑到 30 FPS。避免漏检直接隐藏机械臂、换解跳变和波动深度使整臂突然遮掉。
- 人体分割由每 30 帧加密为每 10 帧，实际模型锚帧 488 帧，其余 4346 帧使用双向光流；合并逐帧手网格轮廓与短时传播。衣物补全与背景供体均排除人体像素。
- 编辑区外在编码前保持原视频解码像素不变；MP4 压缩后不保证逐像素相同。
- 独立正向运动学复算一致，连杆采样点最低高于估计桌面 13.15 mm；未检查完整网格碰撞。

## 缺失观测与尚未验证

- 手部观测缺失：左臂 373 帧，最长连续 0.90 秒；右臂 1244 帧，最长连续 1.93 秒。网页逐帧显示补间估计，数据保存 source_hand_observed 与 display_inferred。
- 夹爪朝向使用向下的简化目标，不恢复真实手掌旋转；未计算旋转准确率，网页不再把占位 0° 显示为精度。
- 相机与尺寸未经标定；拟合误差仅相对于估计目标，不是真实三维准确率。遮挡使用稳定平面近似，不能保证立体衣物遮挡正确。
- 衣物仍来自人类视频，隐藏内容使用估计补全。未执行布料物理、抓持、受力或硬件验证；physics_executed=false、training_eligible=false。不是 EgoMatrix 完整复现。
- 人体分割一致性提示 443 帧需复核。已完成的画面抽查及具体限制见下方记录；模型掩码覆盖率不等同于真实人体去除准确率。
