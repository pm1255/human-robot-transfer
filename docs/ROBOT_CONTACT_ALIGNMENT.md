# 人手轮廓与末端对齐：原因和修复原则

目前确认了两类不同问题：背景补全存在手形色差边界；机械臂末端没有完整保持人手的抓取朝向。前者直接留下可见残影，后者影响接触合理性并暴露背景缺陷。机器人轮廓不必与人体轮廓重合，不能以遮住残影代替背景修复。当前输出尚不具备真实抓持或布料物理验证。

## 当前机器人是什么

使用 RoboTwin `aloha-agilex` 资产中的 `arx5_description_isaac.urdf`，机器人名称为 `arx5_description`，抽取 follower arm 的 6 个转动关节和两指平行夹爪，组成双臂。可以称为“当前 ARX5 模型资产”；仅凭目录名不应扩展断言具体采购型号、厂商配置或真实硬件限位。

代码末端安装坐标系是 `fl_link6`，夹爪中心 TCP 是在它的 +X 方向偏移 0.145 m 的近似点。夹爪沿 ±Y 开合；这项偏移是预览代码定义，STL 末端约到 +X 0.15557 m，并非实测标定。应区分安装坐标系、真实机械法兰、夹爪接触中心和人手腕。

## 相对物体关系应该如何保持

以 `T_A_B` 表示 B 坐标系到 A 坐标系的变换。W 为统一世界系，O 为物体系，H 为人体抓取坐标系，G 为夹爪 TCP，F 为法兰/安装坐标系。对于刚体和稳定抓持：

```
T_O_H = inverse(T_W_O) × T_W_H
T_W_G* = T_W_O × T_O_H × T_H_G
T_W_F* = T_W_G* × inverse(T_F_G)
```

`T_H_G` 是人体抓取坐标到机器人抓取坐标的对应关系；不能把人体腕坐标和法兰坐标直接设成相等。接着联合优化关节轨迹、固定基座位置/朝向与接触约束，使 FK 尽量满足末端目标，同时约束限位、速度、加速度、桌面及双臂碰撞。基座不应逐帧移动来掩盖误差。

对于当前 T 恤，应把 O 换成抓取处的**局部布面/材料点坐标系**：沿布料追踪接触点、折边切向和表面法向；接触和松手阶段分别处理。整件衣物的 FoundationPose 结果只是整体代理，不能把它当作每个衣角的刚性坐标系。只有局部可见深度与手部估计时，结果只能称为接触候选，不能称为稳定材料点追踪。

## EgoMatrix 的实际流程

- §3.1 / 附录 A：以手部尺度统一场景，先做源视角与相对深度对齐；多起点联合优化手腕与物体位姿，再固定物体优化手腕和手指关节，缩小接触间隙并抑制穿透。
- §3.2：MANO 关键点到机器人手链接的语义对应，优化机器人腕部与手指，约束限位、朝向、时序和桌面间隙；随后使用 Isaac Lab 中的 PPO 做双手、物体、接触与功率优化。
- §3.3 / 附录 B.1：SAM 分割手、臂、袖子和物体，使用 SVOR 视频修复背景；机器人和物体从同一物理状态共同渲染，再叠回背景并加入模拟阴影。论文并未靠机器人覆盖原人体轮廓来消除残影。
- 附录 E：硬件是双 UR5e + XHand 和 Rainbow Robotics RB-Y1 + XHand；与当前两指 ARX5 资产不同。

## 当前实现的缺口与处理

1. 旧版固定向下的夹爪朝向仅改善显示连续性；新增由腕到捏合中心的接近轴、指尖连线的夹持轴，以及对应的法兰目标。
2. 背景旧版按首个可用邻帧硬贴，曝光差与供体边界形成手形或多边形残影；改为供体亮度匹配、多供体权重融合和梯度域边界衔接。
3. 数值 ±π 范围不是硬件真实限位；连续角度表示避免人工角度边界引入绕转，但这不构成硬件安全验证。
4. 接触估计与工具几何、桌面间隙会冲突。不能只报告中位误差；还要检查误差尾部、不可达帧、穿桌、速度与遮挡，并保留失败标记。
