# 原场景机械臂合成

上一版第九路视频是独立三维场景的运动学预览，缺少原视频背景合成，因此桌面、房间和视角变了。用户要求的输出应是原背景中的机械臂操作画面。本次增加了这条合成流程；这是可检查的视觉试验，补全接缝和局部抠图误差仍会影响画面质量，不能作为机器人成功折衣或可训练动作的证明。

## 画面怎样合成

1. 从源视频分出衣物、手和前臂。移除层使用衣物与人体掩码并集，作为背景恢复的输入。
2. 将相邻帧配准，优先取回原场景可见的桌面像素。没有可靠供体的区域按扫描行估计补全，桌面前沿以下不使用桌面单应变换，避免把桌面拉到地面上。
3. 放回原视频可见的衣物像素，保留演示中的外观和形变。被手挡住的衣物仅在局部轮廓内补全，纹理供体限定为衣物，避免把棕色桌面填进白色衣服。
4. 按原相机内参和估计桌面坐标渲染双 ARX5 机器人，用可见衣物深度处理前后遮挡。渲染使用完整 STL 网格。

最终只改动手臂移除区与机器人覆盖区；每一帧都核对这些区域之外的像素在视频编码前与源解码帧相同。MP4 有损压缩后不保证逐像素相等。清空衣物只发生在中间背景层，最终可见衣物层会放回。

## 分割与补全的证据范围

- SAM3.1 图像检测器在 CPU 上推理 166 个锚帧，其余 4668 帧用双向 DIS 光流传播。不能把全部 4834 帧称为逐帧 SAM 模型推理。
- 前后传播掩码重叠 IoU 小于 0.65 时记录复核标记。这是自动一致性筛查，不是人工准确率。
- 原视频没有记录被手遮住的纹理和衣物真实边界。邻帧供体、扫描行补全、衣物隐藏轮廓都可能出错；当前可以看到接缝、拉伸、阴影残留和局部人体残留。未完成连续视频的独立人工验收。
- 深度与米制尺度仍是单目估计。未验证完整网格碰撞、自碰撞、布料接触和机械臂基座的实际安装。
- 机械臂沿用前一版关节轨迹：10 Hz 求解、30 FPS 展示，缺失检测保持空输出；旧三维预览保留作对照。

## 与 EgoMatrix 的区别

[EgoMatrix §3.3 与附录 B.1](https://arxiv.org/html/2610.18822v1#S3.SS3) 移除人手、手臂、袖子和物体，用 SVOR 做视频补全，然后从同一仿真状态联合渲染机器人和物体，并加入仿真阴影。

本次仅借鉴源场景合成结构。没有运行 SVOR、接触优化、布料仿真、PPO 或联合物理渲染；衣服的运动仍来自人类原视频，所以还不能证明它由机器人带动，也不能称为完整 EgoMatrix 复现。所有轨迹继续标记 `physics_executed=false`、`training_eligible=false`。
