# Public gallery source

The published gallery contains 66 results from 53 unique source clips: 36 annotation previews, 8 arm replacements, 4 humanoid replacements, and 18 robot-to-human variants from 6 clips.

`index.html` is the gallery; `compare.html` provides synchronized robot-to-human inspection. Media are not included in the code repository. Use locally generated outputs under `assets/` and `showcase/` matching the manifests, or view the published site. Dataset rights and attribution appear in the footer. Source manifests intentionally omit server paths and raw action labels.
