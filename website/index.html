不只是换一个更大的模型

当前判断与下一步
01 / 人 → 机器人

先固定几何，再生成外观

现有结果使用关键点拟合、机器人网格和逐帧背景修补。它容易留下人体残影、错误遮挡和漂浮接触。

下一步：视频分割与背景补全 → 标定相机和 IK → 深度/轮廓条件 → 时序视频编辑。

02 / 机器人 → 人手

夹爪不是五指骨架

源视频只有 256²、5 FPS。扩大掩码能给手掌留空间，也可能改坏物体。换成 14B 后仍有夹爪残留和手指融合。

下一步：更清晰源片段 → 目标手姿和抓握约束 → 物体保护 → 局部时序修复。

03 / 是否微调

有条件的小规模适配

不必直接全量微调。先验证姿态、掩码与接触条件；若仍画错本体，再做专门的外观 LoRA 和运动条件适配。

更自然的画面不代表动作等价。所有生成和替换样例的动作训练准入仍未通过验证。
