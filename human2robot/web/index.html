显式路线

视频 → 运动标签 → 预训练

让视觉编码器预测未来手部运动。使用有效标签掩码，并设置错误标签对照。

  • 正确的人类运动标签
  • 打乱对应关系的运动标签

隐式路线

视频 → 未来画面 → 预训练

不显式恢复三维轨迹。先用同一视觉编码器预测未来低分辨率画面，再适配机器人动作。

  • 使用相同来源视频与训练步数
  • 对照当前画面复制基线
  • 再做统一的 RoboTwin 微调
