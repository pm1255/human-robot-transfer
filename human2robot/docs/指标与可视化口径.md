# 指标与可视化口径

本表与网页共享来源，由 `v2/build_review_details.py` 生成。所有未来目标使用有效掩码；预测与实际执行分开。

## 闭环成功率（% / 成功数 ÷ 有效场景数）

**计算：** p = k/n。固定 18 个留出场景，每模型逐场景执行；原生任务判断成功即记 1，400 条命令内未完成记 0。初始化基础设施失败不纳入 n，单独报告。

**来源：** v2/evaluate.py；RoboTwin adjust_bottle 原生 check_success。瓶子功能点：tag=0 时 x<−0.15 m，否则 x>0.15 m；同时 z>0.9 m。

**能说明：** 这是本次比较的主指标，直接检验执行策略是否完成这个任务。专家先筛出的可行场景是条件化评估集合。

**不能说明：** 不能证明其他任务、真实机器人或所有随机场景都有效；正式任务仍排队，开发场景不能混入。

## 95% Wilson 区间（%）

**计算：** z=1.96，d=1+z²/n，中心 c=(p+z²/(2n))/d，半宽 h=z·√(p(1−p)/n+z²/(4n²))/d；报告 [c−h,c+h]。

**来源：** v2/build_results.py::wilson；同一模型的有效场景二元成功结果。

**能说明：** 表达有限场景数量带来的成功率不确定性。例如 0/18 的上界仍约 17.6%，不等于真实成功率严格为零。

**不能说明：** 不是训练随机种子不确定性；区间重叠/不重叠不是配对显著性检验。模型共享场景应做配对比较。

## 离线关节 RMSE / 微调前 → 后（rad）

**计算：** e=预测绝对关节目标−专家绝对关节目标；RMSE=√mean(e²)，汇总 12 个臂关节、有效未来时间步和全部留出窗口。预训练检查点与最终检查点分别计算。

**来源：** v2/train.py::metrics/evaluate；5 个留出机器人 episode；剔除片尾越界目标。

**能说明：** 越低表示预测在留出专家状态附近更像示范；平方对大误差更敏感。0.1 rad 约为 5.7°。

**不能说明：** 不是闭环轨迹误差，也不是末端厘米误差。重叠窗口有相关性，不能把每个窗口当独立场景样本。

## 关节 MAE / 所选维度 MAE（rad；夹爪另计）

**计算：** MAE=mean(|e|)。报告 joint_mae_rad 汇总 12 臂关节；动作图下的 MAE 只取所选样本、所选维度和有效未来步。

**来源：** v2/train.py::metrics 与 web/v2.js::plot。

**能说明：** 平均角度偏差，更容易解释典型误差；图中可定位哪一维和哪段预测偏离专家。

**不能说明：** 不能把单片段 MAE 当全测试集表现；同一个数值对不同关节末端影响不同。

## P95 动作偏差（rad）

**计算：** 把 12 个臂关节的 |e| 合并后取第 95 百分位。95% 的标量关节误差不超过该值。

**来源：** v2/train.py::metrics；与 RMSE 同一有效目标集合。

**能说明：** 检查误差尾部，避免只看平均数遗漏较大的偏差。

**不能说明：** 不是 95% 成功率，也不是最大误差或 95% 置信区间。

## 夹爪 MAE（原生标量）

**计算：** mean(|预测值−专家值|)，只取第 6 和 13 维，使用同样的未来有效掩码。

**来源：** v2/train.py；Aloha 双夹爪控制值。

**能说明：** 检查张合指令预测。执行时另外使用 0.5 阈值化。

**不能说明：** 未标定为毫米，不能解读为指间距离；MAE 低也不代表抓取接触时刻正确。

## 保持当前姿态基线 / 每维 RMSE / 末步误差（rad；夹爪原生单位）

**计算：** 保持基线把当前输入状态重复为所有未来动作；per_dimension_rmse 分别对 14 维求 RMSE；last_horizon 只评估第 16 步且有效的目标。

**来源：** v2/train.py::evaluate 的 persistence、per_dimension_rmse、last_horizon。

**能说明：** 检验模型是否优于不动预测、误差来自哪一关节、远期预测是否恶化。

**不能说明：** 保持基线是离线预测基线，不能据此当成真实静止执行的成功率；最后一步样本子集不同。

## 执行命令与当前状态 MAE / P95（rad）

**计算：** 对实际发出的命令 u_t 和当前原生输入 s_t 求 |u_t−s_t| 的均值/95 分位；排除夹爪两维。

**来源：** v2/evaluate.py：command_state_joint_mae_rad / p95；已核对 s_t 是电机 drive target，而非物理 qpos。

**能说明：** 衡量命令相对当前驱动目标变化有多大，有助于排查突跳或累计漂移。

**不能说明：** 不是物理跟踪误差，也不是专家动作偏差。原生 API 名字含 jointState 并不保证实测角度。

## 命令与执行后物理关节 MAE（rad）

**计算：** mean(|u_t−q_after,t|)，只取 12 个臂关节。q_after 来自 get_*_real_jointState。

**来源：** v2/evaluate.py：command_physical_after_joint_mae_rad；physical_after 轨迹。旧版增量诊断没有此字段。

**能说明：** 检查物理机器人是否跟随命令；大误差可能意味着约束或跟踪困难。

**不能说明：** 再小也不说明命令完成了任务。例如机器人精确地停在瓶子旁仍会失败。

## 命令范围 / 原始到执行目标改变量（rad）

**计算：** 每关节范围=max_t u−min_t u。改变量=mean(|raw_action−action|)，只取臂关节；另有夹爪阈值化。

**来源：** v2/evaluate.py 的 command_joint_range_rad、raw_action/action；网页现场计算改变量。

**能说明：** 暴露动作漂移幅度，以及闲置臂约束到底修改了多少模型输出。

**不能说明：** 不能把控制器修正后的动作全部归功于模型；范围小也可能是策略几乎不动。

## 命令三阶差分（rad / 命令步³）

**计算：** mean(|u[t+3]−3u[t+2]+3u[t+1]−u[t]|)，12 臂关节，至少 4 条命令。

**来源：** v2/evaluate.py：joint_third_difference_per_command。

**能说明：** 描述命令序列的离散抖动趋势。

**不能说明：** 每条命令物理时长不固定，因此不是 rad/s³ 的物理 jerk，也不能直接用于动力学安全判断。

## 瓶子位移 / 目标区域距离（m）

**计算：** 位移=||p_t−p_0||₂。目标区域距离=√(dx²+dz²)，tag=0 时 dx=max(0,x+0.15)，否则 dx=max(0,0.15−x)；dz=max(0,0.9−z)。

**来源：** 仿真瓶子功能点，执行前逐命令采样，最终值单独记录；仅用于评估，不输入策略。

**能说明：** 区分“机械臂动了”与“物体确实被移动”；区域距离说明距离原生任务阈值还有多远。

**不能说明：** 位移大未必方向正确；区域距离不考虑 y，也不刻画路径和接触，距离等于 0 在严格边界处仍不保证成功。

## 动作 / 运动 / 图像 loss（各自归一化平方误差）

**计算：** 动作：14 维标准化目标的有效 MSE；显式运动：双手 0.5 秒后捏合中心 xy 与宽度变化除以 0.1 后的 masked MSE；隐式图像：32×32 RGB 未来残差 MSE。总 loss=动作+0.1×运动+图像（未启用项为 0）。

**来源：** v2/train.py；前 2,000 步联合训练；后 8,000 步各组仅同样机器人动作训练。

**能说明：** 检查各自优化目标是否在收敛。隐式组同时学习机器人动作和人类未来图像；显式组是 2D 运动辅助标签。

**不能说明：** 不同目标尺度不同，不能比较哪组总 loss 更低来判断路线好坏。显式组当前没有使用已验证的重定向机器人动作。

## 人类分支梯度 / 参数变化 / 曝光次数（L2 范数 / 样本次数）

**计算：** 单独对人类辅助 loss 反传，共享编码器梯度 L2=√Σg²；参数变化=||θ_after−θ_before||₂；曝光=更新步数×batch（重复样本也计数）。

**来源：** v2/audit_human_gradient.py 复现初始人类 batch；当前每模型 640,000 次机器人窗口曝光，人类条件 64,000 次人类窗口曝光。第一版还记录参数变化。

**能说明：** 非零梯度证明该分支接入了共享编码器优化；同预算审计减少比较混淆。

**不能说明：** 不证明学到有用知识，更不证明可替代机器人数据；CPU 重放梯度不是所有训练步的梯度统计。

## 检测覆盖 / 全身候选 / 左右手 score（帧数 / 分类得分）

**计算：** 统计每帧输出手数和物体框数；全身候选要求肩、髋、膝、踝通过阈值并在图内。左右手 score 是 handedness 分类结果。

**来源：** v2/annotate.py、review_gate.py；10 Hz 重采样视频；131 片段、10,849 帧。

**能说明：** 显示覆盖缺口和需要人工复查的片段；可定位模型无输出与质检剔除。

**不能说明：** 没有人工真值时不能计算召回率/准确率。最多 1 人、总共 2 手会截断多人；物体框和文字匹配不是接触标注。

## 重定向末端位置 / 旋转误差（mm / rad）

**计算：** 位置=||FK(q).translation−目标.translation||₂；旋转=SO(3) 相对旋转向量的长度。网页显示计算出的同帧误差。

**来源：** h2r/kinematics.py、pipeline.py；第一版 8 段 RGB 与 12 个合成例子；参考 6 轴臂。

**能说明：** 说明逆解关节是否实现给定末端目标；可见目标轨迹与实际 FK 的距离。

**不能说明：** 目标来自人类估计时，逆解准确不代表原始 3D 正确，也不证明抓取成立。

## 几何通过 / 修复帧 / 动作准入（帧数 / 布尔掩码）

**计算：** 几何通过要求人类轨迹有效、IK 检查通过及夹爪估计宽度在 5–85 mm。修复标记表示该帧经过滤波或插值；另记 interpolated_mask。动作准入还检查尺度、相机、接触、镜像、来源等。

**来源：** h2r/pipeline.py 与 repair.py；短缺失插值不跨身份和事件边界，长缺失保持无效。

**能说明：** 把“算出了参考轨迹”“局部几何可行”“允许作为机器人监督”分开。当前真实片段动作准入为 0。

**不能说明：** 通过的代理碰撞仅检查配置的球/平面与连杆近似，不是完整自碰撞、真实网格碰撞或动力学验证。

## 旧版：置乱/置零图像 MSE、常数均值基线（归一化动作 MSE）

**计算：** 把相同验证窗口的图片随机置换或清零后重新预测；常数基线始终输出训练集动作均值。

**来源：** 第一版 web/data/training.json；8 训练、2 留出机器人片段，200 步微调。仅留档，不是本轮主结果。

**能说明：** 变化明显说明模型对输入图片敏感；与简单基线比较可揭示弱模型。

**不能说明：** 分布外置零导致性能下降并不证明使用了任务相关视觉；旧版预算和目标不同，不可与第二版直接排名。
