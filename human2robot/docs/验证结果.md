# 本轮实际结果（2026-09-23）

已完成可运行的第一版数据处理、重定向参考、交互网页，以及单卡小模型训练验证。**尚未完成正式 VLA 训练、RoboTwin 闭环或真机数据替代实验。**

## 数据与几何

- 分别连接并核对 train2（yingbo_train，filesystem 338）和 embody-eval（paratera_ningxia，filesystem 227）。数据来自 train2；同名路径不能跨环境混用。
- EPIC-Kitchens 8 段 RGB 人类操作视频，543 帧；458 帧通过当前手部三维估计的重投影筛选。这是输出可用率，不是独立三维准确率。
- 两段 liuhanyu 候选素材经抽帧核查为机器人视频，未加入人类训练。
- 12 组合成案例覆盖相机移动、抖动、跳点、短/长缺失、阶段边界、身份变化、不可达、尺度未知、夹宽和姿态变化。
- 27 项自动测试通过，见 `outputs/tests.xml` 和 `outputs/tests.log`。包括坐标/旋转、物体相对抓取、FK/IK、限位/速度、碰撞代理、缺失/边界门控、时间修正和导出掩码。
- 8 个原生 LeRobot 人类辅助数据集全部经官方 loader 读回，共 543 帧；见 `outputs/lerobot_roundtrip.json`。是自定义 annotation 数据，不含虚构的 robot action/state。
- 网页 22 个案例逐项切换验证通过；已检查长缺失中段、真实 RGB 关键点叠加和训练结果表，浏览器错误日志为空。

单帧跳点案例的全序列 RMSE 从约 17.73 mm 降至 12.44 mm；轻微抖动仅从 12.63 mm 降至 12.47 mm，收益很小。这里是真值已知的合成测试，不可当成真实视频模型精度。长遮挡的 10 帧保持无效。

真实视频仍缺相机运动补偿、尺度/镜像/接触与机器人外参核验，**真实机器人动作准入为 0**。网页的首帧机器人对齐只是显式标记的运动学演示；不能直接发送给机械臂。当前代码主要验证人类辅助学习与重定向参考的技术接口。

修复了一个在可视化检查中发现的时间问题：Linux OpenCV 读取 MJPEG 代理后，POS_MSEC 指向读完帧的时刻，导致首帧偏移 0.1 秒。现对这种明确记录的均匀代理使用零起点帧网格，修正记录保存在 `outputs/timestamp_correction.json`；原视频 PTS 不做这种假定修正。

## 单卡任务与训练证据

任务 [1053473](https://cybertron.modelbest.co/job-detail?id=1053473&cluster=yingbo_train)，状态 Succeeded。pm 项目、embody-train2、NORMAL、PYTORCHJOB、1 节点 × 1 H100、10 CPU、32 GiB。实际运行环境：H100 80GB，Torch 2.8.0a0，CUDA 12.9；不依据镜像名字猜版本。任务已自行结束。

冻结训练代码位于 train2：`/user/panmiao/workspace/human2robot-rgb-pilot-20260923/releases/pilot_v2`。本地保存原样训练脚本、代码哈希、输入文件哈希、日志与九份 checkpoint，位于 `outputs/training/`。当前源码仅对报告中 implicit 的目标说明做过文字修正，实际运行版本保存在 `train_pilot_used.py`。

人类侧：8 段视频产生 347 个同身份且可见的有效时序窗口。每个条件 120 步、3840 次样本曝光，347 个窗口全部见过，四组使用同一编码器初始化哈希。梯度和编码器参数变化均非零。因此人类数据确实参与优化，而不是只被转换后搁置。

| 人类目标 | 初始目标 loss | 最终目标 loss | 编码器参数变化 L2 |
|---|---:|---:|---:|
| 显式二维运动 | 0.99954 | 0.94051 | 4.39009 |
| 打乱运动标签 | 0.99957 | 1.00091 | 2.09355 |
| 隐式未来图像残差 | 0.01042 | 0.00874 | 3.59639 |
| 两目标组合 | 1.00996 | 0.94844 | 4.38697 |

这些 loss 单位不同，不能用隐式 loss 更小得出隐式更好。隐式目标的“直接复制当前帧”基线为 0.008877，最终值只改善约 1.49%。人类指标来自训练集，原始 session 尚未独立拆分，不能报告人类视频泛化准确率。

## RoboTwin 离线微调

任务为 `adjust_bottle`，8 个 episode / 572 帧训练，另 2 个 episode / 152 帧验证。每个条件同机器人头初始化、同样本顺序、200 步。只迁移视觉编码器，状态/动作来自 RoboTwin 原始 14 维关节字段。

| 初始化 | 留出集标准化动作 MSE ↓ |
|---|---:|
| 直接机器人训练 scratch | 0.06607 |
| 显式人类运动预训练 | 0.05919 |
| 打乱人类运动标签 | 0.06520 |
| 隐式视频预训练 | 0.05466 |
| 显式+隐式 | 0.05997 |
| 保持当前关节状态 | **0.00117** |
| 训练动作均值 | 0.58620 |

最重要的发现是保持当前状态基线远好于所有小模型。密集示教中的下一步关节动作与当前状态相近，单步 MSE 容易被这个性质主导。即使显式/隐式初始化的离线误差小于 scratch，也不能由单种子、两个验证 episode 推断稳定迁移收益。图片置乱会使各小模型误差上升，说明它们用到了图片，但不能证明用对了任务所需的信息。

本轮没有闭环成功率，未计算真机替代率，未评出隐式/显式路线胜者。训练模型是小 CNN，未输入语言，也不是完整 VLA。

## 由这轮结果决定的下一步

1. 先增加独立视频/session 和目标任务相关的人类操作，补相机、尺度、物体接触证据，建立小型人工质检集。不要因准入为零就放宽标准。
2. 将机器人目标改为跨更长时间的动作序列/相对位移，并同时报告保持状态、零增量基线。当前单步目标不足以评价人类先验。
3. 接入实际 VLA，保持机器人动作契约与归一化不变，用独立的人类监督 head 和 mask；加入等计算量机器人-only 对照，至少三种子。
4. 使用真实 Aloha 机器人配置和 RoboTwin 适配器，在 embody-eval 做载入/控制语义 smoke，再做固定种子的闭环评测。未提交无可运行闭环入口的评测任务。
5. 最后按机器人数据占比画数据效率曲线，并在真机独立留出环境复核，才能回答能否替代其他真机数据集。
