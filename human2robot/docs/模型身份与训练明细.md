# 模型身份、实验设计与实际训练记录

随机标签组也改善离线 RMSE，目前不能把收益归因于正确人类运动。正式 8×18 场景闭环作业 1054089 最新查询仍 Queued；没有完整 VLA 成功率，也没有画面转换数据训练 VLA 的结果。

## 模型身份

- **人体 / 手部标注**：MediaPipe Pose Landmarker Full / Hand Landmarker 官方预训练权重。本项目训练 0 步；只推理。输出：身体 33 点；每手 21 点及左右标签。用途：手部二维运动用于 explicit；人体用于质检展示。

- **物体标注**：EfficientDet Lite0 / COCO 官方预训练权重。本项目训练 0 步；只推理。输出：物体类别与二维框。用途：质检展示；未加入本轮策略损失。

- **人 → 机器人画面转换**：无生成基座：启发式掩码 + OpenCV Telea + 机械臂/G1 几何渲染。训练 0 步；G1 每帧数值 IK 不是网络训练。输出：原画 / 删除区域 / 替换画面三栏视频。用途：新增可视化预览，机器人训练准入 0；未进入当前 8 个模型训练。

- **未来图像预测分支**：自定义 CNN 编码器 + MLP，随机初始化，无预训练视觉/语言基座。图像 loss 仅前 2,000 步；共享编码器继续接受 8,000 步动作微调。输出：当前帧 → +0.5s 的 32×32 RGB 残差。用途：implicit_joint 的辅助监督；不是人变机器人模型，也不是视频扩散模型。

- **机器人策略**：同一 CNN 编码器 + 三视角特征拼接 + MLP 动作头；没有语言输入。每条件 2,000 + 8,000 = 10,000 步，随机种子 17 / 29。输出：16×14 绝对关节/夹爪目标；每次执行前 4 条。用途：小型视觉行为克隆（BC）；未训练完整 VLA。

## 训练配置

- robot_episodes: 50

- split: [40, 5, 5]

- split_seed: 429

- human_clips: 96

- human_windows: 9433

- human_valid_hand_targets: 4509

- review_only_clips: 35

- image_input: 128×128 RGB; robot has head/left/right views

- horizon: 16

- optimizer: AdamW

- learning_rate: 0.0002

- weight_decay: 0.0001

- gradient_clip_norm: 1.0

- robot_batch: 64

- human_batch: 32

- stage1: 2000

- stage2: 8000

- robot_exposures: 640000

- human_exposures: 64000

- seeds: [17, 29]

- checkpoint_selection: 固定第 2,000/10,000 步；没有按测试分数挑选检查点

- validation: 按 episode 保留 5 条 validation；当前脚本未用它早停或选模型

- fairness: 同随机种子相同初始化/机器人 batch 序列/步数，人体辅助计算量额外增加，未做严格等 FLOPs 对照

- image_schedule: 第 2,001 步起图像/运动辅助 loss 停用。此时曲线的 0 表示未优化，不是完美重建。
