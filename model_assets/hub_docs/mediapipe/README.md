# MediaPipe detection models

This folder contains Hand Landmarker, Pose Landmarker Full, and EfficientDet Lite0. Upstream: https://ai.google.dev/edge/mediapipe/solutions/vision . Apache-2.0 license: [MediaPipe.txt](../licenses/MediaPipe.txt).

Companion GitHub scripts: [tools/run.py](https://github.com/pm1255/human-robot-transfer/blob/main/tools/run.py), [run_mediapipe_hand.py](https://github.com/pm1255/human-robot-transfer/blob/main/human2robot/v2/run_mediapipe_hand.py). [Download and verify](https://github.com/pm1255/human-robot-transfer/blob/main/tools/model_assets.py) using the repository manifest. No annotation data is included.
